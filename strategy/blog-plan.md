# 용리치의 성장연구소 — 실행 계획

- 블로그: https://yongrich-growthlab.tistory.com
- 현재 글 수: **0편** (2026-09-01 확인)
- 목표: 100편 이상 발행 → 유입 확보 → 애드센스 수익화

## 1. 카테고리 재편안

기존 이름(`성장`)을 살리면서 수익 라인을 얹습니다. **기존 카테고리는 지우지 말고 아래처럼 정리**하세요.

| 카테고리 | 하위 | 역할 | 목표 편수 |
|---|---|---|---|
| **부의 성장** | 지원금·환급 ⭐신규 | 정부지원금, 세금환급 — **애드센스 단가 최상** | 35 |
| | 절약·생활금융 ⭐신규 | 통신비, 전기요금, 보험 청구절차 | 20 |
| | 주식투자 (기존) | 저빈도. 종목 추천 금지 (유사투자자문 리스크) | 5 |
| | 투자철학 (기존) | 에세이. 브랜딩용 | 3 |
| | 부동산 임장노트 (기존) | 유지 | 3 |
| **생활의 성장** ⭐신규 | — | 정부24 발급, 전입신고, 여권 등 **진입 가장 쉬움** | 30 |
| **지식의 성장** | 독서노트 (기존) | 브랜딩용, 저빈도 | 5 |
| **커리어 성장** | (기존) | 저빈도 | 5 |
| **성장하는 라이프** | 포토그래피 (기존) | 유지 | 3 |
| | 리뷰 ⭐신규 | 애드센스 승인 **후** 오픈. 쿠팡 파트너스 | 10 |

**⭐신규 4개만 만들면 됩니다.** 나머지는 그대로 두세요.

> 왜 "생활의 성장"인가: 등본 발급·전입신고 같은 글은 경쟁이 약해서 신규 블로그도 1~2개월이면 상위에 걸립니다. 이걸로 색인과 신뢰도를 먼저 만들고, 그 위에 단가 높은 지원금·환급 글을 얹는 순서입니다.

## 2. 발행 일정 (주 4편 기준)

| 구간 | 기간 | 누적 | 비중 | 할 일 |
|---|---|---|---|---|
| 1구간 | 1~4주 | 16편 | 생활의 성장 70% / 지원금 30% | 색인 안정화, GSC 등록 |
| 2구간 | 5~8주 | 32편 | 생활 50% / 지원금 50% | **⚑ 애드센스 신청 (30편 시점)** |
| 3구간 | 9~16주 | 64편 | 생활 40% / 지원금·환급 60% | 승인 후 광고 배치 최적화 |
| 4구간 | 17~26주 | 104편 | 성과 상위 카테고리로 자동 집중 | 갱신 큐 가동 |

**약 6개월에 100편.** 주 4편은 자동 파이프라인이 감당 가능하고, 구글이 자연스럽게 받아들이는 속도입니다.

> 더 빠르게 가려면 `.env` 의 `POSTS_PER_WEEK` 를 올리면 됩니다. 다만 주 7편을 넘기면 신규 블로그에서는 위험 구간입니다.

## 3. 애드센스 신청 시점 판단 기준

30편을 넘겼을 때 아래를 **모두** 만족하면 신청:

- [ ] 발행 30편 이상, 각 1,500자 이상
- [ ] 최근 8주간 꾸준한 발행 이력 (몰아쓰기 흔적 없음)
- [ ] 필수 페이지 3종 (소개 / 개인정보처리방침 / 문의)
- [ ] GSC에서 **색인 생성됨** 페이지가 20개 이상
- [ ] 자연 검색 유입이 발생하고 있음 (하루 10명 이상)

봇이 `/status` 에서 이 진행도를 계속 추적합니다.
