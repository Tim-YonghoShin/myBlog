# 플랫폼 세팅 — 티스토리 + 네이버 투트랙

## 결론 먼저

| 플랫폼 | 애드센스 | 쿠팡 파트너스 | 주 유입원 | 역할 |
|---|---|---|---|---|
| **티스토리** | ✅ 가능 | ✅ 가능 | 구글·다음 | **메인** (수익 담당) |
| 네이버 블로그 | ❌ 불가 (애드포스트만) | △ 제한적 | 네이버 | 서브 (유입·브랜딩) |
| 자체 도메인 | ✅ 가능 | ✅ 가능 | 구글 | 나중에 이전 고려 |

애드센스를 주 수익으로 하신다면 **티스토리가 메인**입니다. 네이버는 같은 주제로 요약본을 올려 네이버 검색 유입을 잡는 용도로만 쓰세요 (단, 동일 원문 복붙은 양쪽 다 손해 — 아래 참고).

## 티스토리 초기 세팅 체크리스트

- [ ] 블로그 개설, 주소는 **주제와 연관된 영문 단어** (예: `money-guide`)
- [ ] 스킨: 반응형 + 로딩 빠른 것. 기본 제공 "Poster" / "Odyssey" 무난
- [ ] **개인 도메인 연결** (선택이지만 강력 추천, 연 1~2만원)
  - 이유: 티스토리 정책 변경 시에도 방문자·백링크를 지킬 수 있음. 나중에 자체 사이트로 이전 가능
- [ ] 카테고리 3~5개로 시작 (너무 잘게 쪼개지 말 것)
- [ ] 필수 페이지 3종 (애드센스 승인 요건):
  - 블로그 소개 / 작성자 소개
  - 개인정보처리방침
  - 문의(이메일)
- [ ] 프로필 사진·닉네임·한 줄 소개 채우기

## 검색엔진 등록 (개설 직후 바로)

| 도구 | URL | 하는 일 |
|---|---|---|
| Google Search Console | search.google.com/search-console | 색인 요청, 검색 성과 확인 — **가장 중요** |
| 네이버 서치어드바이저 | searchadvisor.naver.com | 네이버 노출 등록 |
| 빙 웹마스터 | bing.com/webmasters | 부수적이지만 5분이면 끝 |

티스토리는 sitemap이 `https://주소/sitemap.xml` 로 자동 생성됩니다. 세 곳 모두에 제출하세요.
Google Analytics(GA4)도 함께 연결해두면 나중에 어떤 글이 돈이 되는지 추적 가능합니다.

## 네이버 서브 운영 시 주의

원문을 그대로 복사해 양쪽에 올리면 중복 콘텐츠로 둘 다 불이익입니다. 대신:

1. 티스토리에 **전체 버전** (2,000자+, 표·이미지 포함)
2. 네이버에 **요약 버전** (800~1,000자, 다른 문장으로 재작성) + "자세한 내용은 블로그에" 링크

네이버는 외부 링크를 좋아하지 않으므로 링크는 본문 하단에 하나만.

## 발행 리듬

- 초기 8주: **주 3~4편** (총 25~30편) → 애드센스 신청
- 이후: 주 2~3편 유지 + 기존 글 갱신 1편

갱신이 신규만큼 중요합니다. 정책·세금 글은 매년 숫자만 바꿔 재발행하면 검색 순위가 유지됩니다.
