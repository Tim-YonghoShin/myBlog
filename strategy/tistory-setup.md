# 티스토리 개설 — 따라하기

소요 시간 약 30분. 순서대로 하시면 됩니다.

## 1. 블로그 개설

1. [tistory.com](https://www.tistory.com) → 카카오 계정으로 로그인
2. **블로그 만들기** → 아래 3개를 입력

| 항목 | 값 | 주의 |
|---|---|---|
| 블로그 주소 | (아래에서 선택) | **한 번 정하면 못 바꿉니다.** 영문 소문자, 하이픈만 |
| 블로그 이름 | (아래에서 선택) | 나중에 변경 가능 |
| 블로그 설명 | 한 줄 소개 | 검색결과에 노출됨 |

> 주소는 변경 불가입니다. 원하는 주소가 이미 쓰이고 있으면 뒤에 `-kr`, `-note` 정도만 붙이세요. 숫자는 붙이지 마세요 (스팸으로 보입니다).

## 2. 카테고리 (이 구조 그대로)

관리 → **카테고리 관리** 에서 아래 5개를 순서대로 만듭니다. 하위 카테고리는 만들지 마세요 — 글이 쌓인 뒤에 쪼개는 게 맞습니다.

| # | 카테고리 | 담는 글 | 수익 라인 |
|---|---|---|---|
| 1 | 정부지원금·정책 | 근로장려금, 청년지원, 바우처, 지역화폐 | 애드센스 |
| 2 | 세금·환급 | 연말정산, 종소세, 자동차세, 재산세 | 애드센스 (단가 최상) |
| 3 | 생활금융 | 통신비, 전기요금, 보험 청구절차, 신용점수 | 애드센스 |
| 4 | 생활정보·서류 | 정부24 발급, 전입신고, 여권, 검진 | 애드센스 (진입 쉬움) |
| 5 | 리뷰 | 직접 구매한 제품만 | 쿠팡 파트너스 |

**초기 8주는 1·2·4번에만 씁니다.** 3번은 신뢰도가 쌓인 뒤, 5번은 애드센스 승인 후에 엽니다.

## 3. 스킨

관리 → 꾸미기 → 스킨변경. **Poster** 또는 **Odyssey** 권장.

- 이유: 반응형 + 가벼움. 티스토리 트래픽의 70% 이상이 모바일입니다.
- 화려한 스킨은 로딩이 느려지고 애드센스 광고 배치가 꼬입니다.

설정에서 아래는 꼭 켜세요:
- [ ] 사이드바에 **카테고리** 노출
- [ ] 글 하단에 **관련 글** 노출 (체류시간 ↑)
- [ ] 목차(TOC) 기능 있으면 켜기

## 4. 필수 페이지 3종 (애드센스 승인 요건)

관리 → **페이지** 에서 3개를 만듭니다. 만든 뒤 **블로그 하단 메뉴에 연결**하세요.

| 페이지 | 내용 | 준비된 원고 |
|---|---|---|
| 블로그 소개 | 누가, 왜 이 주제를 쓰는지 3~5줄 | 아래 §6 |
| 개인정보처리방침 | 쿠키·광고 고지 포함 | `content/templates/privacy-policy.md` (빈칸만 채우기) |
| 문의하기 | 이메일 주소 | 아래 §6 |

> **YMYL 주제(금융·세금)라 "블로그 소개"가 특히 중요합니다.** 구글은 돈 관련 정보에서 "누가 썼는지"를 봅니다. 익명 블로그는 상위 노출이 어렵습니다.

## 5. 설정 체크리스트

관리 → 블로그 설정:
- [ ] **주소 설정**: 글 주소를 `숫자` 대신 **`문자`** 로 변경 → SEO에 유리
- [ ] **RSS 전체 공개**
- [ ] 댓글: 승인 후 노출 (스팸 방지)
- [ ] 저작물 사용 허가: CC 표시 없이 기본값

## 6. 복사해서 쓰는 원고

### 블로그 소개 (예시 — 본인 상황에 맞게 수정)

```
정부지원금과 세금 환급, 직접 신청해보고 정리합니다.

공고문은 길고 어렵게 쓰여 있어서 "나는 해당되나?"를 알기까지가 제일 오래 걸립니다.
그 부분만 빠르게 확인할 수 있게, 자격 조건과 신청 절차를 표로 정리합니다.

모든 글은 해당 기관의 공식 공고를 근거로 작성하며, 확인한 날짜를 함께 적어둡니다.
제도는 매년 바뀌기 때문에 기준일이 지난 글은 주기적으로 갱신하고 있습니다.

문의: (이메일)
```

### 문의하기

```
블로그 내용에 대한 문의, 정정 요청, 제휴 문의는 아래로 연락 주세요.

이메일: (이메일 주소)

- 게시글의 정보가 최신이 아니거나 사실과 다른 부분을 발견하시면 알려주세요. 확인 후 수정하겠습니다.
- 제도·정책 관련 개별 상담은 해당 기관에 문의하시는 것이 정확합니다.
```

## 7. 개설 후 즉시 (검색엔진 등록)

| 도구 | 주소 | 할 일 |
|---|---|---|
| Google Search Console | search.google.com/search-console | 속성 추가 → 소유권 확인 → `sitemap.xml` 제출 |
| 네이버 서치어드바이저 | searchadvisor.naver.com | 사이트 등록 → 소유확인 → 사이트맵 제출 |
| 빙 웹마스터 | bing.com/webmasters | GSC에서 가져오기로 3분이면 끝 |

사이트맵 주소는 `https://블로그주소/sitemap.xml` 입니다.
