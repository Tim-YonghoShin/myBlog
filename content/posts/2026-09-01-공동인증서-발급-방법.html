기준일: 2026년 9월 1일. 인증서 발급 화면 구성과 수수료는 기관별로 다르니, 금액이 걸린 항목은 해당 금융기관·인증기관 공고를 직접 확인해 보시면 돼요.

정부24에 로그인하려는데 "공동인증서를 등록하세요"만 계속 뜨는 상황, 저도 처음엔 한참 헤맸어요. 알고 보니 순서가 잘못된 거였더라고요.

결론부터 말하면 정부24와 홈택스는 공동인증서를 발급하는 곳이 아니에요. 발급은 은행·우체국·증권사 같은 등록대행기관이나 인증기관에서 하고, 정부24·홈택스에서는 이미 발급받은 인증서를 등록만 하는 구조예요.

그래서 이 글에서는 발급처 고르는 기준부터 발급 절차, 등록까지의 흐름과 만료·비밀번호 분실 같은 예외 상황을 순서대로 정리했어요.

2020년 12월 10일 전자서명법 개정안 시행으로 공인전자서명 제도가 폐지됐어요. 기존 공인인증서가 사라진 게 아니라 이름이 '공동인증서'로 바뀐 것이고, 지금도 그대로 쓸 수 있어요.

나는 어떤 방법으로 받아야 할까요

  • 이미 해당 은행 인터넷뱅킹·모바일뱅킹에 가입돼 있어요 → 은행 갈 필요 없이 홈페이지·앱에서 바로 발급돼요
  • 인터넷뱅킹은 안 했고 계좌만 있어요 → 은행에 가서 인터넷뱅킹 신청부터 해야 해요
  • 거래 은행이 아예 없어요 → 계좌 개설 + 인터넷뱅킹 신청 후에 발급
  • 은행 업무가 아니라 공공 민원·연말정산이 목적이에요 → 용도제한용 공동인증서나 금융인증서, 간편인증으로도 대부분 처리돼요
  • 사업자·법인이에요 → 용도(전자세금계산서, 전자입찰 등)에 맞는 사업자용 인증서가 필요하고, 준비 서류가 개인과 달라요

발급 절차, 세 가지로 나눠볼게요

방법 1. 은행 방문형 (인터넷뱅킹 미가입자)

  1. 신분증, 도장, 통장을 챙겨서 거래 중인 은행·증권사·우체국에 가고, 인터넷뱅킹(또는 사이버트레이딩)을 신청해요.
  2. 창구에서 신분 확인을 하면 참조번호와 인가코드를 줘요. 임시 아이디·비밀번호 역할을 하는 값이라 종이를 잃어버리면 곤란해요.
  3. 집에서 그 기관 홈페이지에 접속해 인증센터 메뉴로 들어가서 참조번호와 인가코드를 입력하고, 안내되는 인증 프로그램을 설치해요.
  4. 인증서 비밀번호를 설정해요. 공동인증서 비밀번호는 영문+숫자+특수문자 조합이어야 해요.
  5. 발급된 인증서를 USB 같은 이동식 저장매체나 스마트폰에 저장해요. PC 하드디스크에만 두는 건 보안상 권장되지 않아요.

방법 2. 비대면 발급 (인터넷뱅킹 가입자)

  1. 은행·증권사 홈페이지나 앱에 로그인한 뒤 인증센터 → 인증서 발급/재발급 선택
  2. 인증서 종류(개인 / 은행·보험용 / 범용) 선택
  3. 휴대폰 본인확인, 계좌·비밀번호·보안매체(OTP, 보안카드) 입력으로 본인 확인
  4. 저장 위치 선택 후 비밀번호 설정 → 발급 완료

메뉴 이름이 은행마다 조금씩 달라서 어렵게 느껴지는데, 막상 들어가 보면 '인증센터' 안에 다 모여 있어요.

방법 3. 금융인증서로 우회하기

보안 프로그램 설치가 부담스럽다면 금융결제원 금융인증서가 대안이에요. 발급은 거래 은행 사이트에서 하고, 절차는 본인 인증 → 이름·휴대전화번호·생년월일 입력 → SMS 확인코드 확인 → 6자리 숫자 비밀번호 설정 순서예요.

발급만 하면 끝이 아니에요, 등록까지 해야 해요

  • 정부24: 아이디 로그인 후 My GOV → 나의 인증관리 → 인증등록/관리에서 인증서를 등록해요. 등록 전에 회원가입이 돼 있어야 해요.
  • 홈택스: 로그인 후 상단 인증센터 → 공동·금융인증서 등록 클릭
  • 스마트폰으로 옮길 때: PC에서 모바일 인증서 이동 서비스(smart.mobile.go.kr)에 접속해 '스마트폰으로 인증서 내보내기'를 실행해요.

이런 경우엔 어떻게 하나요

유효기간이 이미 지나버렸어요

갱신은 만료일 30일 전부터만 가능하고, 만료일이 지난 인증서는 갱신이 안 돼요. 이때는 갱신이 아니라 신규 발급 절차를 처음부터 다시 밟아야 해요. 기관에 따라 지사를 다시 방문해야 하는 경우도 있고요.

USB에 복사해둔 인증서는 그대로예요

PC에서 갱신을 끝냈어도 따로 저장해둔 인증서는 자동으로 갱신되지 않아요. 저도 이 부분에서 한 번 당황했는데, 갱신한 뒤에 USB 등에 다시 복사해줘야 하고 이때 기존 인증서는 덮어써져요.

비밀번호를 잊어버렸어요

공동인증서 비밀번호는 재설정이 아니라 재발급으로 해결해요. 재발급·갱신은 인증서를 처음 발급받은 기관에서 처리한다는 점도 기억해두시면 좋아요.

자주 묻는 질문

공인인증서가 없어졌다는데 공동인증서는 왜 아직 쓰나요?

폐지된 건 '공인'이라는 우월적 법적 지위예요. 인증서 자체는 공동인증서로 이름만 바뀌어 유지되고, 민간 전자서명과 동등한 효력을 가져요.

은행에서 무료로 받은 인증서로 공공 민원이 되나요?

행정안전부의 용도제한용 공동인증서 이용방침에 따라 등록할 수 있는 인증서 범위가 정해져 있어요. 등록 가능 목록은 정부24 인증서 안내 화면에서 확인해 보시면 돼요.

범용 인증서는 얼마인가요?

용도제한용은 무료로 발급·갱신되는 사례가 많고 범용은 유료예요. 다만 금액은 인증기관·발급 채널에 따라 달라서 발급 기관 공고를 직접 확인하는 게 정확해요.

꼭 공동인증서여야 하나요?

행정안전부 통합인증(Any-ID) 기준으로 공공 웹사이트 인증수단은 모바일신분증, 간편인증, 공동인증서, 금융인증서, 민간ID 등 5종이에요. 은행 업무나 특정 업무용 인증이 아니라면 간편인증만으로 끝나는 경우도 많아요.

인증기관 연락처는 어디서 찾나요?

위택스 안내 기준 인증기관은 코스콤, 한국정보인증, 금융결제원, 한국전자인증, 한국무역정보통신, 한국인터넷진흥원 전자서명인증관리센터예요. 금융결제원 발급분은 발급받은 은행 홈페이지를 참고하라고 안내되고 있어요.

인증서 종류에 따라 사용 가능한 사이트와 수수료가 달라져요. 개별 사안은 발급 기관이나 정부민원안내 콜센터 110으로 문의해 보세요.

정리하면

순서는 딱 두 단계예요. 은행·우체국·증권사에서 발급받고, 정부24·홈택스에서 등록하는 거죠.

인터넷뱅킹에 이미 가입돼 있다면 앱 인증센터에서 10분 안에 끝나고, 미가입이면 신분증·도장·통장을 챙겨 창구부터 들러야 해요.

공공 민원만 볼 목적이라면 금융인증서나 간편인증이 더 편할 수 있으니, 내 용도부터 정하고 발급처를 고르는 게 시간을 아끼는 방법이에요. 🙂
