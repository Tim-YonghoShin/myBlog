기준일: 2026년 9월 1일. 인증서 발급 화면 구성과 수수료는 기관별로 다르므로, 금액이 걸린 항목은 해당 금융기관·인증기관 공고를 직접 확인해야 합니다.

정부24나 홈택스에 로그인하려는데 "공동인증서를 등록하세요"만 반복되는 상황이라면, 순서가 잘못됐을 가능성이 큽니다. 정부24와 홈택스는 공동인증서를 발급하는 곳이 아닙니다. 발급은 은행·우체국·증권사 같은 등록대행기관 또는 인증기관에서 하고, 정부24·홈택스에서는 이미 발급받은 인증서를 등록만 합니다.

2020년 12월 10일 전자서명법 개정안 시행으로 공인전자서명 제도가 폐지됐습니다. 기존 공인인증서는 없어진 것이 아니라 이름이 '공동인증서'로 바뀌었을 뿐이며, 지금도 계속 쓸 수 있습니다.

나는 어떤 방법으로 발급받나

  • 이미 해당 은행 인터넷뱅킹·모바일뱅킹에 가입돼 있다 → 은행 방문 없이 홈페이지·앱에서 바로 발급 가능
  • 인터넷뱅킹 미가입, 계좌만 있다 → 은행 방문해 인터넷뱅킹 신청부터 필요
  • 거래 은행이 아예 없다 → 계좌 개설 + 인터넷뱅킹 신청 후 발급
  • 은행 업무가 아니라 공공 민원·연말정산 목적이다 → 용도제한용 공동인증서 또는 금융인증서, 간편인증으로도 대부분 처리 가능
  • 사업자·법인이다 → 용도(전자세금계산서, 전자입찰 등)에 맞는 사업자용 인증서 필요, 필요 서류가 개인과 다름

발급 절차

방법 1. 은행 방문형(인터넷뱅킹 미가입자)

  1. 신분증, 도장, 통장을 지참해 거래 중인 은행·증권사·우체국을 방문하고 인터넷뱅킹(또는 사이버트레이딩)을 신청합니다.
  2. 창구에서 신분 확인 후 참조번호와 인가코드를 받습니다. 임시 아이디·비밀번호 역할을 하는 값이므로 종이를 잃어버리지 않도록 합니다.
  3. 집에서 해당 기관 홈페이지에 접속해 인증센터 메뉴로 들어가 참조번호와 인가코드를 입력하고, 안내되는 인증 프로그램을 설치합니다.
  4. 인증서 비밀번호를 설정합니다. 공동인증서 비밀번호는 영문+숫자+특수문자 조합이어야 합니다.
  5. 발급된 인증서를 USB 등 이동식 저장매체나 스마트폰에 저장합니다. PC 하드디스크 단독 저장은 보안상 권장되지 않습니다.

방법 2. 비대면(인터넷뱅킹 가입자)

  1. 은행·증권사 홈페이지 또는 앱 로그인 후 인증센터 → 인증서 발급/재발급 선택
  2. 인증서 종류(개인 / 은행·보험용 / 범용) 선택
  3. 휴대폰 본인확인, 계좌·비밀번호·보안매체(OTP, 보안카드) 입력으로 본인 확인
  4. 저장 위치 선택 후 비밀번호 설정 → 발급 완료

방법 3. 금융인증서(공동인증서 대안)

보안 프로그램 설치가 부담이면 금융결제원 금융인증서가 대안입니다. 발급은 거래 은행 사이트에서 하며, 절차는 본인 인증 → 이름·휴대전화번호·생년월일 입력 → SMS 확인코드 확인 → 6자리 숫자 비밀번호 설정 순입니다.

발급 후 등록까지 해야 끝난다

  • 정부24: 아이디 로그인 후 My GOV → 나의 인증관리 → 인증등록/관리에서 인증서 등록. 등록 전에는 회원가입이 되어 있어야 합니다.
  • 홈택스: 로그인 후 상단 인증센터 → 공동·금융인증서 등록 클릭
  • 스마트폰으로 옮길 때: PC에서 모바일 인증서 이동 서비스(smart.mobile.go.kr) 접속 후 '스마트폰으로 인증서 내보내기' 실행

예외 상황

유효기간이 이미 지났다면

갱신은 만료일 30일 전부터만 가능하고, 만료일이 지난 인증서는 갱신할 수 없습니다. 이 경우 갱신이 아니라 신규 발급 절차를 다시 밟아야 합니다. 기관에 따라 지사 재방문이 요구되는 경우도 있습니다.

USB에 복사해둔 인증서가 그대로라면

PC에서 갱신을 완료해도 별도 저장매체에 복사해둔 인증서는 자동으로 갱신되지 않습니다. 갱신 후 USB 등에 다시 복사해야 하며, 이때 기존 인증서는 덮어써집니다.

비밀번호를 잊었다면

공동인증서 비밀번호는 재설정이 아니라 재발급으로 해결합니다. 재발급·갱신은 인증서를 처음 발급받은 기관에서 처리합니다.

자주 묻는 질문

공인인증서가 없어졌다는데 공동인증서는 왜 아직 쓰나요?

폐지된 것은 '공인'이라는 우월적 법적 지위입니다. 인증서 자체는 공동인증서로 이름이 바뀌어 유지되며, 민간 전자서명과 동등한 효력을 갖습니다.

은행에서 무료로 받은 인증서로 공공 민원이 되나요?

행정안전부의 용도제한용 공동인증서 이용방침에 따라 등록 가능한 인증서 범위가 정해져 있습니다. 등록 가능 목록은 정부24 인증서 안내 화면에서 확인할 수 있습니다.

범용 인증서는 얼마인가요?

용도제한용은 무료 발급·갱신인 사례가 많고 범용은 유료입니다. 다만 금액은 인증기관·발급 채널에 따라 다르므로 발급 기관 공고 확인이 필요합니다.

꼭 공동인증서여야 하나요?

행정안전부 통합인증(Any-ID) 기준 공공 웹사이트 인증수단은 모바일신분증, 간편인증, 공동인증서, 금융인증서, 민간ID 등 5종입니다. 은행 업무나 특정 업무용 인증이 아니라면 간편인증만으로 처리되는 경우도 많습니다.

인증기관 연락처는요?

위택스 안내 기준 인증기관은 코스콤, 한국정보인증, 금융결제원, 한국전자인증, 한국무역정보통신, 한국인터넷진흥원 전자서명인증관리센터입니다. 금융결제원 발급분은 발급받은 은행 홈페이지를 참고하도록 안내되고 있습니다.

인증서 종류에 따라 사용 가능한 사이트와 수수료가 달라집니다. 개별 사안은 발급 기관 또는 정부민원안내 콜센터 110으로 문의하세요.
